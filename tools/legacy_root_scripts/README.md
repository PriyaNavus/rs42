# Historical development scripts

These scripts were used while constructing and revising the RS42 environments,
encodings, evaluation, and UI. They are retained for provenance, not as current
setup or evaluation entry points. Some assume their former location at the
repository root and may need path adjustments if rerun.

Use the documented commands in the root README and the scripts under
`tools/final_evaluation/` for the final evaluation. The canonical run table is
`experiments/final_evaluation/results/runs/all_runs.csv`.
